==================== SECTION 1: QUESTION DETAILS ====================

A string [b]S[/b] of length [b]n[/b] contains only A and B. A single pass examines adjacent positions (1,2), (2,3), ..., (n-1,n) in that order. Whenever the current pair is BA, it is swapped to AB. Later comparisons use the already modified string.
Exactly one comparison is omitted: that comparison makes no change, even if it would have swapped BA. All other comparisons proceed normally. The omitted comparison may also be one where no swap would occur.
You are given an observation string [b]T[/b] of the same length. Each A or B in [b]T[/b] must match the resulting character at that position; ? means that position is unknown. Find the smallest 1-based position of an omitted comparison that is consistent with all observations. If none is possible, the answer is [b]-1.[/b]
[b]You are required to debug the following function:[/b]
[code-c]int* MidnightDispatch(int n, char* source, char* observed, int* returnSize);[/code][code-cpp]vector&lt;int&gt; MidnightDispatch(int n, string&amp; source, string&amp; observed);[/code][code-java]static int[] MidnightDispatch(int n, String source, String observed)[/code][code-python]def MidnightDispatch(n, source, observed):[/code]

The function accepts [b]n[/b] and the strings [b]S[/b] (source) and [b]T[/b] (observed). It must return a single array containing one integer: the smallest valid omitted comparison position, or -1 if none exists. In C, the size of the returned array is stored in [b]returnSize.[/b]

[b]Note:[/b][ul][li]The pass must use the current, already modified string, not separate swaps on the original string.[/li][li]The omitted comparison may be one that would not change the string.[/li][li]Every visible character of [b]T[/b] (A or B) must match the result.[/li][/ul]
[b]Input Format:[/b][ul][li]The first line contains [b]n.[/b][/li][li]The second line contains the string [b]S[/b] (only A and B).[/li][li]The third line contains the string [b]T[/b] (A, B or ?).[/li][/ul][b]Input will be read from the STDIN by the candidate.[/b]

[b]Output Format:[/b]
Print one integer: the smallest valid omitted comparison position, or [b]-1[/b] if none exists.
[b]The output will be matched to the candidate&#39;s output printed on the STDOUT.[/b]

[b]Constraints:[/b][ul][li]2 &le; [b]n[/b] &le; 800[/li][li][b]S[/b] and [b]T[/b] both have length [b]n[/b][/li][li][b]S[/b] contains only A and B; [b]T[/b] contains only A, B or ?[/li][/ul]
[b]Example:[/b]
[b]Input:[/b]
7
BBAAABA
B?BAA?B
[b]Output:[/b]
3
[b]Explanation:[/b]
With comparison 3 omitted, the pass produces BABAAAB, which agrees with every visible character of [b]T.[/b] Omitting comparison 1 or 2 does not match the observation, so the answer is [b]3.[/b]

[b]Sample Input[/b]
6
BAABAA
AAAB??
[b]Sample Output[/b]

    *returnSize = 1;

        memcpy(work, source, (size_t)n + 1);
