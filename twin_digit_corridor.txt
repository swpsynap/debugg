==================== SECTION 1: QUESTION DETAILS ====================

You are given an array [b]A[/b] of [b]n[/b] integers and two non-negative budgets [b]H[/b] and [b]T.[/b]
Every number [b]A&#91;i&#93;[/b] has two costs. Its head cost is the first (most significant) decimal digit of [b]|A&#91;i&#93;|,[/b] and its tail cost is the last (least significant) decimal digit of [b]|A&#91;i&#93;|.[/b] For [b]A&#91;i&#93;[/b] = 0, both costs are 0.
A non-empty contiguous segment [b]A&#91;L..R&#93;[/b] is called feasible if the sum of head costs of its elements is at most [b]H[/b] and the sum of tail costs of its elements is at most [b]T.[/b]
Find a feasible segment of maximum length. If several feasible segments have the same maximum length, choose the one with the smallest starting position [b]L.[/b] If no feasible segment exists, the answer is [b]0 0 0.[/b]
[b]You are required to debug the following function:[/b]
[code-c]int* TwinDigitCorridor(int n, int H, int T, int* A, int* returnSize);[/code][code-cpp]vector&lt;int&gt; TwinDigitCorridor(int n, int H, int T, vector&lt;int&gt;&amp; A);[/code][code-java]static int[] TwinDigitCorridor(int n, int H, int T, int[] A)[/code][code-python]def TwinDigitCorridor(n, H, T, A):[/code]

The function accepts [b]n, H, T[/b] and the 0-indexed array [b]A.[/b] It must return a single array of three integers [length, L, R], where [b]length[/b] is the maximum feasible segment length and [b]L, R[/b] are the 1-based endpoints of the chosen segment, or [0, 0, 0] if no feasible segment exists. In C, the size of the returned array is stored in [b]returnSize.[/b] The helper headDigit (head_digit in Python) returns the head cost of a number.

[b]Note:[/b][ul][li]Both costs depend only on [b]|A&#91;i&#93;|,[/b] so 47 and -47 each have head cost 4 and tail cost 7.[/li][li]A single element on its own is a segment of length 1.[/li][/ul]
[b]Input Format:[/b][ul][li]The first line contains three integers [b]n, H[/b] and [b]T.[/b][/li][li]The second line contains [b]n[/b] integers [b]A[1], A[2], ..., A[n].[/b][/li][/ul][b]Input will be read from the STDIN by the candidate.[/b]

[b]Output Format:[/b]
Print three space-separated integers: [b]length, L[/b] and [b]R.[/b]
[b]The output will be matched to the candidate&#39;s output printed on the STDOUT.[/b]

[b]Constraints:[/b][ul][li]1 &le; [b]n[/b] &le; 1000[/li][li]&minus;10[sup]9[/sup] &le; [b]A&#91;i&#93;[/b] &le; 10[sup]9[/sup][/li][li]0 &le; [b]H, T[/b] &le; 9000[/li][/ul]
[b]Example:[/b]
[b]Input:[/b]
8 10 14
23 105 48 70 91 16 32 204
[b]Output:[/b]

[b]Explanation:[/b]
The head costs are 2, 1, 4, 7, 9, 1, 3, 2 and the tail costs are 3, 5, 8, 0, 1, 6, 2, 4. Positions 6 to 8 give a head-cost sum of 1 + 3 + 2 = [b]6[/b] &le; [b]10[/b] and a tail-cost sum of 6 + 2 + 4 = [b]12[/b] &le; [b]14,[/b] so the segment is feasible. No feasible segment has length 4 or more, and no earlier segment of length 3 is feasible, so the answer is [b]3 6 8.[/b]
