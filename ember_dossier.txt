==================== SECTION 1: QUESTION DETAILS ====================

Two sequences [b]A[/b] (length [b]P[/b]) and [b]B[/b] (length [b]Q[/b]) are read by separate iterators, each starting before its first value. An action labelled A consumes the next unread value of [b]A,[/b] and an action labelled B consumes the next unread value of [b]B.[/b] An action is legal only if the chosen sequence still has an unread value.
Immediately after each action, a watcher reports the sum of the next unread value of [b]A[/b] and the next unread value of [b]B,[/b] where a sequence with no unread values contributes 0.
You are given a recorded history of [b]M[/b] actions, each with its label and watcher report, in their original order. The full history had exactly [b]M + 1[/b] actions, but one complete record was lost. Find where the missing action could be inserted, and its label, so that every action is legal and every recorded report is correct. The missing action has no report to check.
Positions are 1-based in the reconstructed history. If several reconstructions work, choose the smallest position, and A before B at the same position. If none works, the answer is [b]-1.[/b]
[b]You are required to debug the following function:[/b]
[code-c]int* EmberDossier(int P, int Q, int M, int* V, char* S, int* W, int* returnSize);[/code][code-cpp]vector&lt;int&gt; EmberDossier(int P, int Q, int M, vector&lt;int&gt;&amp; V, string&amp; S, vector&lt;int&gt;&amp; W);[/code][code-java]static int[] EmberDossier(int P, int Q, int M, int[] V, String S, int[] W);[/code][code-python]def EmberDossier(P, Q, M, V, S, W):[/code]

The function accepts [b]P, Q, M,[/b] a single 0-indexed array [b]V[/b] of length [b]P + Q[/b] holding the values of [b]A[/b] followed by the values of [b]B[/b] (so [b]A&#91;i&#93;[/b] is [b]V&#91;i&#93;[/b] and [b]B&#91;j&#93;[/b] is [b]V&#91;P + j&#93;[/b]), the string [b]S[/b] of the [b]M[/b] recorded labels and the 0-indexed array [b]W[/b] of their watcher reports. It must return a single array of two integers [position, label], where label is 0 for A and 1 for B, or [-1, -1] if no reconstruction exists. In C, the size of the returned array is stored in [b]returnSize.[/b]

[b]Note:[/b][ul][li]The missing action may be placed before the first recorded action, between any two of them, or after the last.[/li][li]The recorded history may be inconsistent with every possible reconstruction; then the answer is [b]-1.[/b][/li][/ul]

    result[0] = -1;
    result[1] = -1;
    *returnSize = 2;
    for (int g = 0; g < M; g++)
    {
        for (int c = 0; c < 2; c++)
        {
            int x = 0, y = 0, ok = 1;
            for (int j = 0; j <= M && ok; j++)
            {
                char act;
                int r = -1;
                if (j == g)
                    act = (c == 0) ? 'A' : 'B';
                else
                {
                    r = (j < g) ? j : j - 1;
                    act = S[r];
                }
                if (act == 'A')
                {
                    if (x > P)
                        ok = 0;
                    x++;
                }
                else
                {
                    if (y >= Q)
                        ok = 0;
                    y++;
                }
                if (ok && r != -1)
                {
                    int frontA = (x < P) ? V[x] : 0;
                    int frontB = (y < Q) ? V[P + y] : 0;
                    if (frontA + frontB != W[r])
                        ok = 0;
                }
            }
            if (ok)
            {
                result[0] = g + 1;
                result[1] = c;
                return result;
            }
        }
    }

}
